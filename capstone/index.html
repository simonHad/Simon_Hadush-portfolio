Foundations of Artificial Intelligence and Machine Learning

Course Overview

A comprehensive 10-week introductory course on AI and Machine Learning principles, algorithms, and applications.

Course Description

This comprehensive introductory course provides learners with a solid foundation in artificial intelligence and machine learning principles, algorithms, and applications. Over ten weeks, participants develop the skills needed to understand, implement, and evaluate machine learning models across supervised, unsupervised, and deep learning paradigms. The course emphasizes practical application through hands-on coding exercises, real-world case studies, and a culminating capstone project.

Target Audience

Early-career data professionals, software developers transitioning to AI roles, graduate students in related fields, and professionals seeking to understand and apply AI/ML techniques in their domains. Prerequisites include basic programming knowledge (preferably Python) and foundational mathematics (calculus, linear algebra, and statistics at an introductory level).

Theoretical Foundations

This course integrates multiple learning theories to create a comprehensive learning experience. Behaviorist principles are applied to foundational skill development through structured exercises with immediate feedback. Cognitivist principles guide content organization, advance organizers, and cognitive load management. Constructivist principles inform project-based learning and authentic problem-solving activities. Connectivist principles address the networked nature of AI knowledge, helping learners develop skills in navigating documentation, online resources, and professional communities.

SMART Learning Objectives

Upon completion of this course, learners will be able to:

  • Differentiate between supervised, unsupervised, and reinforcement learning paradigms, and select appropriate algorithms for given problem types and data characteristics. (Analyze)
  • Implement at least five core machine learning algorithms (including linear regression, logistic regression, decision trees, k-means clustering, and neural networks) using Python and standard libraries such as scikit-learn and TensorFlow. (Apply)
  • Evaluate machine learning model performance using appropriate metrics (accuracy, precision, recall, F1-score, ROC-AUC, and others), and diagnose issues such as overfitting, underfitting, and data leakage. (Evaluate)
  • Design and execute an end-to-end machine learning project—from data preprocessing and exploratory analysis through model selection, training, evaluation, and deployment considerations—on a real-world dataset. (Create)
  • Analyze the ethical, social, and professional implications of AI systems, including bias, fairness, transparency, and privacy concerns, and apply responsible AI practices in development workflows. (Analyze)
  • Explain the fundamental concepts of deep learning, including neural network architectures, backpropagation, and optimization algorithms, and apply these concepts to simple computer vision or natural language processing tasks. (Understand / Apply)

Sample Quiz Questions and Feedback

Quiz Question 1 (at 5:00):
What is the role of an activation function in a neural network?

  • A) To initialize the weights randomly
  • B) To introduce non-linearity into the network
  • C) To calculate the loss function
  • D) To update the weights during backpropagation

Correct Answer: B
Feedback: Correct! Activation functions like ReLU, sigmoid, and tanh introduce non-linearity, allowing the network to learn complex patterns. Without them, the network would only be able to model linear relationships.
Incorrect Feedback: Not quite. The activation function's main purpose is to introduce non-linearity. Try again!

Quiz Question 2 (at 11:00):
During backpropagation, how is the error distributed to earlier layers?

  • A) By randomly assigning error to each neuron
  • B) By calculating the gradient of the loss function with respect to each weight
  • C) By re-running forward propagation
  • D) By adjusting the learning rate

Correct Answer: B
Feedback: Correct! Backpropagation uses the chain rule to compute gradients, which tell us how much each weight contributed to the error. These gradients are then used to update the weights.

Recommendations for Improvement

  1. Add audio descriptions for complex visual elements not already described in narration (e.g., detailed mathematical notation).
  2. Provide a text-based alternative for the interactive quiz for learners who cannot access the video player.
  3. Offer a slower playback option for learners who need more time to process complex visual information.
  4. Create supplementary written tutorials with static diagrams for learners who prefer text-based learning.
  5. Add a code-along version where learners can execute the neural network code in their own environment alongside the video.

Feedback Strategy Reflection

How feedback will be utilized to improve course design, enhance learner engagement, and support continuous improvement.

1. Feedback for Learners (Formative and Summative)

Feedback in this AI and Machine Learning course is designed to be timely, specific, and actionable—critical in a field where misconceptions can compound rapidly. For formative assessments, I provide immediate automated feedback on coding exercises and knowledge checks, explaining not only what is incorrect but also why and how to correct it. For programming assignments, I use a combination of automated testing (to verify functionality) and human review (to assess code quality, design decisions, and reasoning).

For summative assessments, I use rubrics to provide structured feedback that addresses each criterion. Beyond the rubric scores, I include narrative comments that celebrate strengths and offer concrete suggestions for improvement. In a field like machine learning where "there is no single right answer," this dual approach—rubric scoring plus narrative feedback—ensures learners understand both their performance level and the specific steps they can take to grow.

2. Feedback from Learners (Course Improvement)

Learner feedback is systematically collected through multiple channels:

  • End-of-unit pulse checks: Brief surveys asking learners to rate their confidence with the material, identify challenging concepts, and suggest improvements.
  • Mid-course evaluation: A comprehensive survey at the end of Unit 5 to identify areas for adjustment before the second half of the course.
  • End-of-course evaluation: Detailed survey addressing all aspects of the course design, materials, and facilitation.

3. Peer Feedback Mechanisms

Structured peer feedback activities are incorporated in Units 5, 7, and 9, using clear rubrics to guide evaluation. This serves multiple purposes: it reduces the instructor's feedback burden, exposes learners to diverse approaches, and develops critical evaluation skills.

4. Data-Driven Continuous Improvement

I analyze assessment data to identify patterns of learner difficulty. For example:

  • If multiple learners struggle with a particular quiz question about backpropagation, I review whether the instructional materials adequately explain the concept.
  • If learners consistently perform poorly on a specific coding exercise, I may need to provide additional scaffolding or practice opportunities.
  • If discussion forums show recurring questions about a topic, I create supplementary resources.

This analysis drives iterative refinements to course content, activities, and assessments.

5. Instructor Self-Reflection

I maintain a design journal throughout the course, documenting what worked well and why, what could be improved and how, unexpected challenges and how they were addressed, and observations about learner engagement and understanding.

6. Closing the Feedback Loop

I communicate to learners how their feedback has been incorporated. When learners see their suggestions implemented, they feel valued and more engaged. I share a "You Said, We Did" summary after each course iteration, demonstrating responsiveness and building trust.

Cognitivism Explanatory feedback helps learners understand concepts; metacognitive prompts develop self-regulation.
